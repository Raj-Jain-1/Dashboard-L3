AI Smart Hospital Analytics Platform

A futuristic full-stack hospital analytics platform powered by AI-driven insights, real-time monitoring, predictive healthcare analytics, and an immersive cyberpunk-inspired dashboard UI.

🚀 Overview

The AI Smart Hospital Analytics Platform is designed to help hospitals monitor operations, optimize resources, and gain intelligent insights through advanced analytics and AI simulations.

The platform combines:

⚡ Real-time healthcare monitoring
🤖 AI-powered predictive analytics
📊 Interactive dashboards & visualizations
🧠 Smart chatbot assistant
🌌 Cyberpunk glassmorphism UI
🏥 Hospital resource management

Built with a modern Flask-based architecture for maximum customization and scalability.

⚙️ Installation

1️⃣ Clone the Repository
git clone https://github.com/your-username/ai-smart-hospital.git
cd ai-smart-hospital

2️⃣ Create Virtual Environment
Windows
python -m venv venv
venv\Scripts\activate
Linux / Mac
python3 -m venv venv
source venv/bin/activate

3️⃣ Install Dependencies
pip install -r requirements.txt

4️⃣ Run the Application
python app.py

Server will start at:
[https://dashboard-l3.onrender.com](https://dashboard-l3.onrender.com)
Use Id - admin ,
Pass - admin123
